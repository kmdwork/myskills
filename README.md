# myskills

自作または調整した Codex 向け skill をまとめて管理するリポジトリです。

現在は、各 skill を `plugins/` ディレクトリ直下へ個別に配置しています。それぞれのディレクトリにある `SKILL.md` が、skill の目的、利用条件、作業手順を定義します。

## 収録している skills

### design-extractor

既存アプリケーションの実装を調査し、色、タイポグラフィ、コンポーネント、レイアウト、レスポンシブ規則などのデザイン言語を `DESIGN.md` と `design-audit.md` に整理する skill です。

### design-steward

ソフトウェアの要件定義と設計、既存システムの設計意図の分析、設計変更の整合性確認を支援する skill です。確認済みの事実、推定、提案、未決定事項を区別し、重要な設計判断を承認前に正式な方針として確定しないための判断基準と成果物テンプレートを含みます。

### github-public-audit

ローカルの Git リポジトリを公開する前に、秘密情報、個人情報、内部識別子、Git 履歴などの公開リスクを検査する skill です。監査用スクリプトとテストを含みます。

### html

概念、仕組み、調査結果を、HTML を使った視覚的な説明ドキュメントとして作成する skill です。共通の CSS、コンポーネント例、数式コピー用スクリプト、PDF レンダリング用スクリプトを含みます。

### plan-from-issue

GitHub Issue と対象リポジトリを分析し、実装は行わずに、レビュー可能な作業フェーズと受け入れ条件を含む実装計画を作成する skill です。

## ファイルの役割

- `SKILL.md`: skill のメタデータ、起動条件、手順、制約を定義します。
- `agents/openai.yaml`: OpenAI/Codex 上で表示する名称や説明などの設定です。
- `assets/`: skill が成果物の作成時に利用するテンプレートなどを格納します。
- `references/`: 詳細な手順、判断基準、分類規則などの補足資料を格納します。
- `scripts/`: skill が利用する実行可能な補助処理やテストを格納します。
- `design-system/`: HTML ドキュメントで共有するスタイルや部品を格納します。

## 現在のパッケージ形態

現時点では `.codex-plugin/plugin.json` やマーケットプレイス定義を置いていないため、`plugins/` 全体がインストール可能な単一 Codex プラグインになっているわけではありません。現在の構成は、5つの skill のソースをこのリポジトリでまとめて管理するためのものです。
